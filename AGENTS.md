# hex-truncated-series-mathlib

This repository is a published mirror of `HexTruncatedSeriesMathlib` in
[hex-dev](https://github.com/kim-em/hex-dev), the source of truth for Hex.
Develop and verify changes in hex-dev; its release sync publishes this library,
its SPEC, README, Lake dependencies and CI workflow here.

Do not edit managed source or workflows in this mirror. Report issues and open
implementation PRs in hex-dev. Follow that repository's AGENTS.md, SPEC and PLAN
instructions when working there.

The mirror's CI builds its published library on the pinned Lean toolchain.
Benchmarks, conformance fixtures, oracles and development phase audits remain
in hex-dev and are not part of this mirror.
